Question 2 Answers

Part a

The first two predictors are nearly identical, so they create a direction with very little information. That makes the contrast \(\widehat\beta_1-\widehat\beta_2\) much noisier than the sum \(\widehat\beta_1+\widehat\beta_2\).

  y <- mu + rnorm(n)
  y_test <- mu + rnorm(n)

  for (l in seq_along(lambda_grid)) {
    lambda <- lambda_grid[l]

      crossprod(X) + n * lambda * diag(p),
      crossprod(X, y_centered)

    test_mse[k, l] <- mean((y_test - y_hat)^2)

Typical results are:

  • OLS: individual coefficients have large variation, especially \(\widehat\beta_1-\widehat\beta_2\).
  • \(\lambda=0.02\): variance drops sharply with only a small change in the fitted values.
  • \(\lambda=0.2\): variance is smallest, but bias is larger and test MSE rises.

Part c

The sum \(\widehat\beta_1+\widehat\beta_2\) is a stable direction because it aligns with the main signal. The difference \(\widehat\beta_1-\widehat\beta_2\) is the weak direction, so it is highly sensitive to noise. Ridge shrinks the weak direction most strongly, reducing variance without greatly changing the fitted value in the major signal direction. The cost is bias when the true model needs that weak direction.

Question 3 Answers

Part a

The ridge objective is

\[ L_\lambda(\beta)=\frac{1}{2n}\|\widetilde y-X\beta\|_2^2 + \frac{\lambda}{2}\|\beta\|_2^2. \]

Differentiating gives

\[ \nabla L_\lambda(\beta) = -\frac{1}{n}X^\top(\widetilde y-X\beta)+\lambda\beta. \]

Setting this to zero yields

\[ \left(X^\top X+n\lambda I_p\right)\widehat\beta_\lambda = X^\top\widetilde y. \]

For \(\lambda>0\),

\[ a^\top (X^\top X+n\lambda I_p)a = \|Xa\|_2^2+n\lambda\|a\|_2^2 > 0 \]

for all nonzero \(a\), so the matrix is positive definite and invertible, even if \(X\) is rank deficient or \(p>n\).

Part b

Using the compact SVD \(X=U_rD_rV_r^\top\), the ridge estimator can be written as

\[ \widehat\beta_\lambda = V_r(D_r^2+n\lambda I_r)^{-1}D_rU_r^\top \widetilde y. \]

Thus the fitted mean in the \(j\)th left singular-vector direction is multiplied by

\[ \rho_j(\lambda)=\frac{d_j^2}{d_j^2+n\lambda}. \]

With \(n=100\) and \(\lambda=0.01\),

\[ \rho_1 = \frac{10^2}{10^2+100(0.01)} = \frac{100}{101} \approx 0.9901, \]

\[ \rho_2 = \frac{2^2}{2^2+1} = \frac{4}{5}=0.8, \]

\[ \rho_3 = \frac{0.2^2}{0.2^2+1} = \frac{0.04}{1.04} \approx 0.0385. \]

So

\[ \operatorname{df}_{\mathrm{eff}}(0.01)=1+0.9901+0.8+0.0385\approx 2.8286. \]

The weakest direction receives the strongest shrinkage. This can reduce prediction variance when that direction is noisy, but it creates substantial prediction bias if the true signal has a large component there.

Question 4 Answers

Part a

The condition number is the ratio of largest to smallest eigenvalue.

For \(A_0 = \frac{1}{n}X^\top X\) with eigenvalues \(9\) and \(0.01\),

\[ \kappa(A_0)=\frac{9}{0.01}=900. \]

With ridge,

\[ A_\lambda = A_0 + \lambda I_p, \quad \lambda=0.09, \]

so the eigenvalues become \(9.09\) and \(0.10\). Hence

\[ \kappa(A_\lambda)=\frac{9.09}{0.10}=90.9. \]

The ridge penalty makes the objective less elongated and easier to optimize numerically.

Part b

For the error vector \(e^{(k)}=\beta^{(k)}-\widehat\beta_\lambda\), gradient descent gives

\[ e^{(k+1)} = (I-\eta A_\lambda)e^{(k)}. \]

In an eigendirection with unpenalized eigenvalue \(a\), the corresponding eigenvalue of \(A_\lambda\) is \(a+\lambda\), so the component is multiplied by

\[ 1-\eta(a+\lambda). \]

For stability in every eigendirection,

\[ |1-\eta(a+\lambda)|<1, \]

which holds for

\[ 0<\eta<\frac{2}{M},\quad M=9.09. \]

So the admissible interval is approximately

\[ 0<\eta<0.2200. \]

For \(\eta=1/M\), the contraction factors are

\[ 1-\frac{9.09}{9.09}=0, \qquad 1-\frac{0.10}{9.09}\approx0.9890. \]

The strong direction converges in one step; the weak direction contracts slowly.

For \(\eta=2.1/M\), the strong direction factor is

\[ 1-\frac{2.1(9.09)}{9.09} = -1.1, \]

so the method diverges if there is any nonzero component in that eigendirection.

Part c

A larger \(\lambda\) improves conditioning, but it also changes the statistical estimator by shrinking coefficients more aggressively. The goal of tuning \(\lambda\) should be predictive performance, not fastest optimization. Cross-validation or GCV is therefore the correct statistical rule.

Part a

real <- read.csv("data/realestate.csv")
folds <- read.csv("data/realestate-split-folds.csv")

train_df <- real %>%
  inner_join(folds %>% select(row_id, split, cv_fold), by = "row_id") %>%
  filter(split == "train")

features <- c("date", "age", "distance", "stores", "latitude", "longitude")
response <- "price"

lambda_grid <- c(0, 10^(-4 + 0.05 * 0:120))

cv_mse <- sapply(lambda_grid, function(lambda) {
  fold_errors <- numeric(10)

  for (fold in 1:10) {
    val_idx <- train_df$cv_fold == fold
    train_idx <- !val_idx

    x_tr <- as.matrix(train_df[train_idx, features])
    x_va <- as.matrix(train_df[val_idx, features])
    y_tr <- as.numeric(train_df[train_idx, response])
    y_va <- as.numeric(train_df[val_idx, response])

    x_means <- colMeans(x_tr)
    x_sds <- apply(x_tr, 2, sd)
    x_sds[x_sds == 0] <- 1

    x_tr_s <- sweep(sweep(x_tr, 2, x_means, "-"), 2, x_sds, "/")
    x_va_s <- sweep(sweep(x_va, 2, x_means, "-"), 2, x_sds, "/")

    beta_hat <- solve(
      crossprod(x_tr_s) + nrow(x_tr_s) * lambda * diag(ncol(x_tr_s)),
      crossprod(x_tr_s, y_tr - mean(y_tr))
    )

    y_hat <- mean(y_tr) + as.vector(x_va_s %*% beta_hat)
    fold_errors[fold] <- mean((y_va - y_hat)^2)
  }

  c(mean = mean(fold_errors), se = sd(fold_errors) / sqrt(10))
})

cv_summary <- data.frame(
  lambda = lambda_grid,
  mean_mse = cv_mse[1, ],
  se = cv_mse[2, ]
)

lambda_min <- cv_summary$lambda[which.min(cv_summary$mean_mse)]
threshold <- cv_summary$mean_mse[which.min(cv_summary$mean_mse)] +
  cv_summary$se[which.min(cv_summary$mean_mse)]

lambda_1se <- max(cv_summary$lambda[cv_summary$mean_mse <= threshold])

Part b

x_all <- as.matrix(train_df[features])
y_all <- as.numeric(train_df[[response]])

x_means <- colMeans(x_all)
x_sds <- apply(x_all, 2, sd)
x_sds[x_sds == 0] <- 1
x_all_s <- sweep(sweep(x_all, 2, x_means, "-"), 2, x_sds, "/")

gcv <- sapply(lambda_grid, function(lambda) {
  XTX <- crossprod(x_all_s) + nrow(x_all_s) * lambda * diag(ncol(x_all_s))
  beta_hat <- solve(XTX, crossprod(x_all_s, y_all - mean(y_all)))
  y_hat <- mean(y_all) + as.vector(x_all_s %*% beta_hat)
  train_mse <- mean((y_all - y_hat)^2)

  sv <- svd(x_all_s, nu = 0, nv = 0)$d
  df_eff <- 1 + sum((sv^2) / (sv^2 + nrow(x_all_s) * lambda))
  gcv_value <- train_mse / (1 - df_eff / nrow(x_all_s))^2
  c(train_mse = train_mse, df_eff = df_eff, gcv = gcv_value)
})

Part c

fit_ridge <- function(x, y, lambda) {
  x_means <- colMeans(x)
  x_sds <- apply(x, 2, sd)
  x_sds[x_sds == 0] <- 1
  x_s <- sweep(sweep(x, 2, x_means, "-"), 2, x_sds, "/")

  beta_hat <- solve(
    crossprod(x_s) + nrow(x_s) * lambda * diag(ncol(x_s)),
    crossprod(x_s, y - mean(y))
  )
  list(beta = beta_hat, mean = mean(y), x_means = x_means, x_sds = x_sds)
}

train_x <- as.matrix(train_df[features])
train_y <- as.numeric(train_df[[response]])

# final test split
final_test <- real %>%
  inner_join(folds %>% select(row_id, split), by = "row_id") %>%
  filter(split == "test")

x_test <- as.matrix(final_test[features])
y_test <- as.numeric(final_test[[response]])

models <- list(
  OLS = 0,
  lambda_min = lambda_min,
  lambda_1se = lambda_1se,
  lambda_gcv = lambda_gcv
)

for (nm in names(models)) {
  lam <- models[[nm]]
  fit <- fit_ridge(as.matrix(train_x), train_y, lam)
  x_tr_s <- sweep(sweep(as.matrix(train_x), 2, fit$x_means, "-"), 2, fit$x_sds, "/")
  x_te_s <- sweep(sweep(as.matrix(x_test), 2, fit$x_means, "-"), 2, fit$x_sds, "/")

  train_pred <- fit$mean + as.vector(x_tr_s %*% fit$beta)
  test_pred <- fit$mean + as.vector(x_te_s %*% fit$beta)

  train_mse <- mean((train_y - train_pred)^2)
  test_mse <- mean((y_test - test_pred)^2)

  sv <- svd(x_tr_s, nu = 0, nv = 0)$d
  df_eff <- 1 + sum((sv^2) / (sv^2 + nrow(x_tr_s) * lam))

  cat(nm, "training MSE =", round(train_mse, 3),
      "test MSE =", round(test_mse, 3),
      "df_eff =", round(df_eff, 3), "\n")
}

The numbers show the same pattern as the theory: the ridge penalty reduces coefficient variance, and the selected model should be fixed using only training data before looking at the test response. The MSE table is used for comparison, not model selection after the fact.

Final interpretation

Ridge regression stabilizes highly variable coefficient directions, especially when predictors are correlated. It trades some variance for bias, and the best penalty is the one that balances that tradeoff on validation data or through GCV, not the one that looks best after seeing the test error.
